Privacy Policy

Last updated: October 17, 2026.

Color Scheme Studio is a static website operated by the owner of the linked project repository. This version has no advertising code, analytics, contact forms, accounts, or application cookies.

Search and browsing

Searches and category selections are processed in your browser. Search terms may appear in the page URL and your browser history. This application does not store them in a database.

Hosting and external links

The site is hosted on GitHub Pages. GitHub processes technical requests to serve the site; see GitHub’s privacy statement. Fonts and application assets are served with the site. Linked third-party websites have their own practices.

Clipboard and downloads

Copy buttons write only the selected color value or starter CSS to your clipboard when you choose them. The application does not read your clipboard. CSS downloads are static files.

Advertising

No ads are active in this version. This policy will be updated to describe the actual vendors, cookies, and relevant consent choices before advertising is enabled.

Contact

For privacy questions, contact the project owner through the project issue tracker. Do not post sensitive details publicly.
