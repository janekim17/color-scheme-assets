CHOOSE A USE, THEN A COMBINATION

Best for event identities, premium packaging and short covers

Near-black, deep plum, umber, copper, and gold suit compact, dramatic work. This is a strong cover and identity palette, but it does not contain a quiet light reading surface for a long document.

Where this palette needs help

For long schedules, reports, or help pages, add a light neutral. Three dark swatches alone will not create three clear information levels.

02

This is a cover palette, not a complete report system

Use the deep shades for a short title, product face, or event announcement. When several paragraphs or a timetable are required, introduce a warm off-white with a checked dark foreground. Record that extra neutral explicitly instead of forcing copper into a reading role.

03

Dark shades need visible boundaries

Black, plum, and umber can look distinct as swatches but merge as neighboring panels. Separate them with space, a light rule, or a labeled inset. For print, request a proof: screen luminance does not predict the separation of dark inks on paper.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
