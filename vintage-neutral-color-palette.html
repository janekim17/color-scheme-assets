CHOOSE A USE, THEN A COMBINATION

Best for editorial identities, portfolios and reading-led documents

Cool gray, sage gray, rust, charcoal, and taupe suit editorial systems that need restraint without becoming monochrome. Rust gives the palette a clear warm direction; charcoal supplies a useful reading anchor.

Where this palette needs help

The middle neutrals can merge. They are useful for atmosphere and grouping, but poor substitutes for explicit chart labels or important boundaries.

02

Use the neutrals for grouping, not five data classes

Choose one neutral for the page and one for a supporting panel. Add a heading or rule when their boundary matters. A five-series chart made from these five swatches risks both weak neutral separation and excessive emphasis on the rust series.

03

A neutral identity can still have a warm main field

A rust cover does not need to resemble the gray interior pages. Repeat typography, spacing, and a small taupe marker across the system. For a reading page, move rust back to a compact navigation or editorial detail and keep long paragraphs in charcoal.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
