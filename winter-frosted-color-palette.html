Where this palette needs help

Lavender and muted denim should not carry different meanings solely through hue. Keep labels visible and verify small text separately.

02

A report needs fewer color categories than swatches

Use deep blue for the main series, charcoal for labels, and lavender for a reference area. Add a second series only when the content requires it. A direct label, marker shape, or line style provides a distinction that a subtle blue–lavender shift cannot guarantee.

03

Give tables a reading hierarchy before coloring cells

Keep body values in one dark foreground. Use a single tinted header band or a highlighted result row, rather than tinting every column differently. If a divider is essential to understand the table, do not rely on a barely visible difference between two muted fills.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
