Where this palette needs help

It is not a complete text or dashboard palette. A dark functional neutral is an intentional addition, not a sixth color extracted from the image.

02

Add a foreground before building the layout

Keep the five colors for surfaces and graphics, then introduce #283D42 for text where it reaches the required contrast. Do not darken every original swatch and pretend the extracted palette already included those values. For a functional interface, focus, selected, error, and disabled states require further design.

03

Decorative distinction is not data distinction

Blue and apricot can separate decorative areas without reliably identifying two chart series. For a data-heavy report, use this palette for the cover and section dividers, then develop a checked chart system. For an invitation, a name, date, and place need more contrast than the surrounding motif.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
