FROM INSPIRATION TO APPLICATION

A palette is a starting point. Here is what to make with it.

Try this snow-and-evergreen combination on three different formats, compare the balance, and take away a usable set of color roles—not just five swatches.

01

Same five colors. Three ways to use them.

Change the dominant color and see how the mood shifts.

Color balance
Neutral-led: snow gray gives content room; evergreen supplies structure; berry red draws the eye to one action.
Green-led: the result feels more graphic. Keep the smaller reading areas light and the berry accents sparse.
Sage-led: the same palette becomes softer. Dark text keeps the muted surfaces useful, not just decorative.

Original design studies for this guide. Product names and layouts are illustrative.

04

Take the roles into your project.

Starter CSS for the neutral-led version, including readable supporting text colors.

snowy-berries-palette.cssDownload ↓
/* Snowy berries: an sRGB starting palette. Print values need an output profile. */
:root {
  --winter-surface: #D1D2D4;
  --winter-support: #737E67;
  --winter-ink: #33462F;
  --winter-accent: #BB5041;
  --winter-detail: #AD713B;
  --winter-on-accent: #FFFFFF;
}
.winter-card { background: var(--winter-surface); color: var(--winter-ink); }
.winter-action { background: var(--winter-accent); color: var(--winter-on-accent); }

Choose the version that fits the job.

Start neutral-led when reading content matters most, green-led for a more graphic winter identity, or sage-led for a softer botanical feel. Keep berry red selective. For print, ask for a proof on the actual stock; the CMYK values here are mathematical estimates, not a printer-specific conversion.
