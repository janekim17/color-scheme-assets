02

Choose coral or ochre before you add both

For a service card, reserve coral for the action and remove the ochre decoration. For a catalogue cover, an ochre edition label can replace coral entirely. The five-color palette offers alternatives; it is not a checklist for every page.

03

Separate navigation from urgency

If coral already identifies an important action, do not use it for every section heading. Use weight, spacing, and green text for structure. If red has a warning meaning in your product, give routine actions a different treatment and label warning states explicitly.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
