CHOOSE A USE, THEN A COMBINATION

Best for editorial systems and report covers

Two deep blue-greens, a middle blue, pale lilac, and restrained terracotta offer strong value contrast. This palette can support reading pages as well as dark covers, provided the middle blue is not mistaken for a universal text color.

Where this palette needs help

The two deepest shades can merge in adjacent panels. Use an inset, spacing, or a visible rule when a boundary matters.

02

Let reading pages and covers use different systems

A report cover can use a broad navy field and a short light title. Interior pages need more room for reading: switch the field to pale lilac and keep navy for structure. Carry the identity through repeated typography and a small blue detail rather than repeating the entire cover.

03

Change color area when the format changes

A short cover can carry a broad contrasting field; an interior page may reduce the same color to one marker. If several facts are already highlighted, adding a box around each one creates competition. Choose the area for the amount of content, not a required accent percentage.

04

Take the selected combination with you.

Copy named roles for a document, identity, or web project. The sheet follows the selected use above; it is not a rule to use all five colors everywhere.

Before extending it, test a real heading, a paragraph, a key value, and a secondary detail. Remove colors without a useful role. For printing, request the output profile and inspect a proof; the approximate CMYK values above are not production specifications.
